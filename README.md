# Rock-Paper-and-Scissors-CPP
# ✊ Rock Paper Scissors — C++

A simple **Rock Paper Scissors** game built using **C++**.
The player competes against the computer, and the program determines the winner based on the selected choices.

## 🎮 How It Works

The player chooses one of:

* 🪨 Rock
* 📄 Paper
* ✂️ Scissors

The computer randomly selects one of the three choices.

### Rules

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* Same choice → Draw

## 🛠️ Technologies Used

* **C++**
* `iostream`
* `cstdlib`
* `ctime`

## ▶️ How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder in VS Code or any C++ IDE.

3. Compile the program:

```bash
g++ main.cpp -o game
```

4. Run it:

**Windows:**

```bash
game
```
